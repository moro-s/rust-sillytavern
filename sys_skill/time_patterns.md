# 时间推进模式

## 何时调用 advance_time

当故事中的时间发生**显式跳跃**时，调用 `advance_time`：

| 触发场景 | 对话示例 | 推进量 |
|---------|---------|-------|
| **明确的天数跳跃** | "第二天早上"、"三天后" | 精确到天 |
| **时间段描述** | "一周后"、"过了几个月" | 精确到周/月 |
| **日常时间变化** | "天亮了"、"夜幕降临"、"中午了" | 到半天精度 |
| **场景切换** | "回到酒馆已经是傍晚了" | 描述中自带时间 |
| **等待/休眠** | "等了一个时辰"、"睡了一觉" | 根据上下文 |
| **叙事性跳跃** | "时光飞逝，转眼三年" | 大跨度 |

## label 命名规范

- 使用故事内的时间体系，保持上下文一致
- 格式自由，但要清晰：`第2天早晨`、`三天后的夜晚`、`一周后`
- 如果之前有过时间记录，新标签应基于之前的标签推进
- 首次调用时从 `第1天早晨` 或场景适合的时间开始

## 示例调用

```
用户: "第二天早上，我再次来到酒馆"
→ advance_time(label="第2天早晨", description="剧情推进到第二天")

用户: "等了一周后，伤口终于愈合了"
→ advance_time(label="一周后", description="经过一周的休养")
→ 同时也应该 update 或 delete 状态 "status:受伤"
```

## 不需要调用的场景

- 对话中仅提到时间但没有实际推进（如 "我昨天去了酒馆" 是过去时，不推进时间）
- 几分钟内的微小时间流逝（除非剧情需要精确记录）
- 比喻性质的时间表述

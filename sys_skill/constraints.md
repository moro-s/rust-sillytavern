# 工具调用约束

## 绝对不要做的事

### 1. 不要为纯对话内容调用工具
- 闲聊、问候、打趣 → 不需要工具
- 用户只是描述感受但不影响状态 → 不需要工具
- 回忆过去、讲故事 → 不需要工具

### 2. 不要在不确定时猜测数据
- 如果对话中没有明确说明物品的数量、质量等 → 用默认值或省略
- 如果状态严重程度不明确 → 标记为 "未知" 或用最保守的估计
- **不要编造对话中没有的信息**

### 3. 不要一次对话中重复调用
- 同一轮对话中，同一状态不要 add 两次
- time 不需要每次对话都 advance

### 4. 不要替代用户决策
- 用户没有明确说获得/使用物品 → 不要替用户决定
- 用户没有明确说移动 → 不要替用户决定去了哪里
- 除非对话逻辑上必然发生（如 "我推开门" → 必然进入新地点）

## 调用频率指南

| 频率 | 场景 |
|------|------|
| 几乎每轮都调 | 角色在探险中快速获得/使用物品 |
| 偶尔调用 | 日常对话中偶尔触发状态变化 |
| 很少调用 | 纯社交/情感对话 |
| 不调用 | 闲聊、meta 对话、系统命令 |

## 工具调用后

工具调用完成后，你会在下一轮对话中收到工具执行结果。根据结果调整你的回复：
- 成功 → 在角色回复中自然地反映状态变化
- 失败 → 忽略或用角色口吻表达困惑

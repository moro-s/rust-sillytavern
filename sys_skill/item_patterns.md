# 物品管理模式

## 何时调用 manage_state（物品类）

当对话中出现以下场景时，调用 `manage_state(category="item", ...)`：

| 场景类型 | 对话示例 | 应执行的操作 |
|---------|---------|------------|
| **获得新物品** | "给你一把钥匙"、"捡到一把剑"、"收到了礼物" | `add` |
| **物品丢失/消耗** | "钥匙断了"、"药水喝完了"、"钱花光了" | `delete`（或 `update` 减量） |
| **物品转移** | "把戒指给老板"、"剑被偷了" | `update` 更新 owner |
| **物品使用** | "喝了一瓶治疗药水" | 药水 `delete` + 同时调用 `update` 状态 |
| **物品数量变化** | "又买了3颗宝石" | `update` 更新 qty |
| **装备/卸下** | "穿上铠甲"、"放下盾牌" | `update` 更新 equipped 状态 |
| **损坏/修理** | "剑断了"、"修好了护甲" | `update` 更新 condition |

## key 命名规范

- 格式: `item:物品名`
- 示例: `item:斩龙刀`、`item:治疗药水`、`item:金币`
- 使用对话中出现的物品名称，保持自然

## data 字段建议

```json
// 添加新物品
{"qty": 1, "note": "来自老铁", "quality": "精良"}

// 更新物品
{"qty": 5, "note": "又买了3颗"}

// 装备物品
{"equipped": true}
```

## 示例调用

```
用户: "老铁给了我一把斩龙刀"
→ manage_state(action="add", category="item", key="item:斩龙刀", data={"qty":1,"source":"老铁"})

用户: "我把三颗宝石都卖了"  
→ manage_state(action="delete", category="item", key="item:宝石")

用户: "喝了一瓶治疗药水"
→ manage_state(action="delete", category="item", key="item:治疗药水")
→ 然后在对话描述药水的效果，如果角色状态改善则也更新状态
```

## 不要调用的场景

- 用户只是提到一个物品但没有获得/失去/使用它（如 "我记得那把剑"）
- 用户描述环境中的物品但不与角色互动（如 "桌上有一盏灯"）
- 纯粹的比喻或修辞（如 "我的心像刀割一样"）
